# MAX STUDIO

Android starter project for MAX STUDIO, a video-production app.

## Phase 1 foundation

- Native Android app using Kotlin and Jetpack Compose
- Dark cinematic theme with purple and cyan accents
- Home dashboard with recent-project sample cards
- Create-project screen with name and aspect-ratio selection
- Compose Navigation between dashboard and project setup

## Open in Android Studio

1. Clone this repository and check out the `phase1-max-studio` branch.
2. In Android Studio, choose **Open** and select the cloned repository directory.
3. Install Android SDK Platform 35 if prompted, then sync the Gradle project.
4. Run the `app` configuration on an emulator or Android device.

The project uses JDK 17. Phase 1 stores only in-memory sample data; durable project persistence, media editing, AI services, and YouTube upload are planned for later phases.
